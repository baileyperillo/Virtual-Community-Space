# WEB103 Project 3 - Virtual Community Space - Gym Locator

Submitted by: Bailey Perillo

About this web app: You can use this app to look at gyms. When you click on a gym, it will give you details about it, such as location, description, and types of classes. You can then scroll further to find the available scheduled classes.

Time spent: 65 hours

Describe any challenges encountered while building the app or any additional context you'd like to add.
